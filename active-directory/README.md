# The Mindmap

This Active Directory section started as a transcription and reorganisation of the Orange Cyberdefense **AD mindmap v2025.03**, an openly published Excalidraw diagram covering the domain attack surface end to end.

Every command, technique and tool link in this section comes from that diagram; nothing has been invented. The pages regroup its \~1,090 nodes under this site's phase-based structure.
