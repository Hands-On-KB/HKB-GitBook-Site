# MitMProxy

[https://www.mitmproxy.org/](https://www.mitmproxy.org/)

An HTTPS proxy written in Python and consisting of three different options, as well as a Python library that can be used via an API:

1. mitmdump (CLI version)
2. mitmproxy (Text interface)
3. mitmweb (Web interface)
